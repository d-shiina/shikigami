動作環境

OSWindows 10・11（64 ビット）
権限管理者権限は要りません。使う人のユーザーごとにインストールします
ディスクインストーラーは約 210 MB です。ブラウザ操作や OCR の部品も含みます
ブラウザWeb の操作には Windows に入っている Microsoft Edge をそのまま使います（Chrome も選べます）
AI（作るときだけ）Claude Code・OpenAI Codex・Gemini CLI・GitHub Copilot・Cursor のどれかが使える契約。動かすだけなら AI は要りません

インストールの手順

数分で終わります。終わるとスタートメニューに「SpellSheet Writer」が並びます。

  1. インストーラーをダウンロードする

    上の「ダウンロード」を押すと、SpellSheet.Writer_版_x64-setup.exe が保存されます。

    Edge が「一般的にダウンロードされていません」と止めたときは、ダウンロードの一覧でファイルの「…」から「保存」を選び、次の画面で「詳細表示」→「保持する」を選びます。

  2. Windows の確認画面で「詳細情報」→「実行」を押す

    ダウンロードしたファイルを開くと、青い「Windows によって PC が保護されました」の画面が出ることがあります。左下の「詳細情報」を押すと「実行」ボタンが出るので、それを押します。

    Windows によって PC が保護されました

    Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC に問題が起こる可能性があります。

    詳細情報

    アプリ：
    SpellSheet.Writer_…_x64-setup.exe
    発行元：
    不明な発行元
    実行実行しない

    画面の例です。「詳細情報」を押すまで「実行」は表示されません。

    「発行元：不明な発行元」と出るのは、署名がまだないためです。アプリ名が SpellSheet.Writer_…_x64-setup.exe であることを確かめてから進めてください。

    会社の PC で「実行」が出ないときは、社内の設定でブロックされています。情報システム部門に相談してください。

  3. インストーラーの案内に沿って進める

    「次へ」「インストール」と押して進めます。管理者権限を求める画面は出ません。終わったら「完了」を押します。

  4. SpellSheet Writer を起動する

    スタートメニューから「SpellSheet Writer」を開きます。最初の画面の「何を自動化しますか？」に書いて AI に頼むか、「見本を開く」で完成したフローの中身と動きを確かめられます。

    AI は Writer 右上の「AI チャット」（Ctrl+J）から選んで、その場で導入とサインインができます。ターミナルは要りません。

更新

新しい版が出ると、Writer が起動したときに見つけて裏でダウンロードします。準備ができたら「再起動して更新」を押すか、Writer を閉じたときに入れ替わります。手で入れ直す必要はありません。

アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」で「SpellSheet Writer」を選び、「アンインストール」を押します。

ファイルを確かめたいとき

ダウンロードしたファイルが公開しているものと同じかは、PowerShell で次のように確かめられます。表示された値が、上の「SHA-256」と同じなら同じファイルです。

Get-FileHash "$env:USERPROFILE\Downloads\SpellSheet.Writer_…_x64-setup.exe"

ダウンロードは GitHub（github.com）から直接行われます。それ以外の場所で配られている SpellSheet のインストーラーは使わないでください。
