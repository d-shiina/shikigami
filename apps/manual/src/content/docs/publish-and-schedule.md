## 確定版

SpellSheet のフローには、いま編集している**作業中の内容**と、人が確かめて決めた**確定版**があります。

| 動かし方 | 動く内容 |
|---|---|
| Writer の「実行」 | 作業中の内容（目の前で試す） |
| AI の試し実行 | 作業中の内容 |
| Runner | 確定版 |
| スケジュール（自動実行） | 確定版 |

こうしておくと、AI や人が夜に編集した内容が、翌朝のスケジュールでそのまま業務システムを操作することがありません。確定版がないフローは、Runner にも並ばず、スケジュールでも動きません。

### 確定する

- **確認待ちから**：AI の変更を読んで「変更を承諾」を押すと、その内容が確定版になります（[AI の変更を確認する](../review/)）。
- **変更履歴から**：フローの見出しの行の「変更履歴」→「版」で、「現在の内容を確定」か、過去の版の「この版を確定」を押します。前の版に戻したいときも、作業中の内容を変えずに確定版だけを戻せます。

確定は人だけができます。AI は確定できません。

### 確定を取り消す

「変更履歴」→「版」の「確定を取り消す」で、Runner とスケジュールでそのフローが動かなくなります。

:::note[確定のあとに変えたとき]
確定のあとに変更があると、見出しの行に「確定後に変更があります」と出ます。スケジュールに反映するには、もう一度確定してください。
:::

## Runner で実行する

**SpellSheet Runner** は、確定したフローを選んで実行するだけの小さな画面です。フローを作らない人に向いています。

- 開き方：スタートメニューの「SpellSheet Runner」、Writer のサイドバーの「Runner」、またはタスクトレイのアイコン。
- 使い方：一覧からフローを選び、入力を埋めて「実行」を押します。入力のフォームは、フローの「受け取る」変数から自動で作られます（ファイルやフォルダーは「参照…」、月や日付はカレンダー、選択肢は一覧）。
- 終わると、結果と、作られたファイル（「開く」「フォルダーを開く」）が出ます。エラーのときは、何が起きてどうすればよいかが出ます。解決しないときは、フローの作成者にエラーコードを伝えてください。

:::tip[一日中すぐ使えるようにする]
スタートメニューの「SpellSheet Runner」から開いたときは、Runner を閉じてもタスクトレイに残ります。終えるときはトレイのアイコンを右クリックして「終了」です。
:::

## スケジュールで自動実行する

決まった時刻や、ファイル・メールが届いたときに、確定版のフローを自動で実行できます。Windows のタスク スケジューラーを設定する必要はありません。

### 自動実行を開始する

サイドバーの「自動実行」を開き、「自動実行を開始」を押します。Windows にサインインするたびに自動で始まるよう登録されます。Writer を閉じていても、スケジュールどおりに実行されます。

この裏で動く仕組みを **Worker** と呼びます。PC（と Windows のユーザー、ワークスペース）ごとに 1 つ動きます。

### スケジュールを追加する

「自動実行」の「スケジュールを追加」で、フローといつ動かすかを選びます。

| いつ | 例 |
|---|---|
| 毎日・曜日 | 平日の 8:00。「祝日・会社の休日の除外」も選べます |
| 毎月 | 25 日の 9:00、月末、第 3 営業日、最終営業日。休日に当たったら前の営業日・次の営業日・その月は実行しない、を選べます |
| 一定の間隔 | 9:00〜18:00 の 30 分ごと |
| 1 回だけ | 2026 年 11 月 20 日 8:00 |
| ファイルが届いたら | `input` に `*.xlsx` が置かれたら。届いたファイルのパスを入力の変数に入れて実行します |
| メールが届いたら | 受信トレイに件名「請求書」のメールが届いたら。この PC の Outlook（または Microsoft 365）を 5 分ごとに見ます |

入力のあるフローは、スケジュールごとに入力の値を決めておきます。

### 知っておくこと

- **逃した時刻は取り戻しません。** PC の電源が切れていた、誰もサインインしていなかった間に過ぎた時刻は飛ばし、次の時刻に動きます。
- **同時には 1 つ。** 前の実行が続いているうちに次の時刻が来たら、その回は飛ばします。
- **スケジュールはその PC のものです。** 共有フォルダーのワークスペースを何台かの PC で使っても、スケジュールを作った PC だけが動かします。
- **会社の休日** は、ワークスペースの `holidays.json` に書きます。日本の祝日は最初から入っています。

```json
{
  "formatVersion": 1,
  "holidays": ["2026-12-29", "2026-12-30", "2026-12-31"],
  "workdays": ["2026-11-28"]
}
```

## 画面を操作するフローと画面ロック

マウスやキーボードを使うフロー（デスクトップアプリ・ブラウザの操作）は、**画面がロックされていると動けません**。Windows がロック中の画面への入力を許さないためです。

- 予定の時刻には、PC にサインインしたまま、画面をロックしないで置いてください。「自動実行」の一覧には、その PC が操作のないまま何分でロックされるかが出ます。
- 実行中は、画面が消えたりスリープしたりしないよう SpellSheet が抑えます。ただし、会社の設定によるロックや <kbd>Win</kbd>+<kbd>L</kbd> は止められません。
- ファイルや Excel、Web API だけのフローは、ロック中でも動きます。

:::tip[リモートデスクトップで使っている PC]
リモートデスクトップの窓を閉じて切断すると、画面がロックされます。代わりに「自動実行」の「画面を残して切断」で切断すると、ロックしないまま切断でき、フローが動き続けます（管理者の確認が出ることがあります）。
:::

## 終わったことを知らせる

無人で動いたフローが失敗したときに、Teams や Slack に知らせることができます。ワークスペースの `policy.json` に送り先を書きます。

```json
"notify": [
  { "webhook": "https://….logic.azure.com/workflows/…", "format": "teams" }
]
```

既定では失敗したときだけ知らせます。成功したとき、人の操作を待ち始めたときにも知らせたいときは `"on": ["failed", "succeeded", "waiting"]` を足します。Webhook の URL はパスワードと同じように扱ってください。

## 無人実行を止める

特定のフローを無人では動かしたくないときは、そのフローを開いて「設定」→「実行の許可」の「このフロー」で「無人実行」の「許可する」を外します。Writer からはこれまでどおり実行できます。
