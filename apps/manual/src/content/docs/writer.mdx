Writer は、フローを作る・直す・試す・確定するための画面です。フローを 1 つ開いたときの画面は次のようになっています。

## 上の帯

| 場所 | 内容 |
|---|---|
| 左の「SpellSheet Writer」 | メニュー。ほかのページ（下の表）、Runner、表示テーマ、言語、設定を開きます |
| その右の「確認待ち」「シークレット」 | あなたの確認や入力を待っているものがあるときだけ、件数が出ます |
| 真ん中の「AI に頼む・フローや操作を探す」 | AI に頼みたいことを書いて送るか、フロー・ページ・操作の名前で探して開きます（<kbd>Ctrl</kbd>+<kbd>P</kbd>） |
| 「AI チャット」 | 右に AI と話す欄を開きます（<kbd>Ctrl</kbd>+<kbd>J</kbd>） |

「SpellSheet Writer」のメニューから開くページは次のとおりです。

| 項目 | 内容 |
|---|---|
| フロー | このワークスペースのフローの一覧。新しいフローを作る、ファイルから読み込むのもここです |
| 確認待ち | AI が変えたフローの一覧。読んで「変更を承諾」するまで、ここに残ります（[AI の変更を確認する](../review/)） |
| 業務の棚卸し | AI が業務を聞き取り、自動化の候補を出します |
| 自動実行 | この PC のスケジュールと、自動実行（Worker）が動いているか（[確定とスケジュール実行](../publish-and-schedule/)） |
| シークレット | ログインの ID・パスワードや Web API のキー（[ログイン情報と個人情報](../secrets/)） |
| プラグイン | 後から足した機能の一覧 |
| Runner | 確定したフローを実行するだけの画面を、別のウィンドウで開きます |
| 設定 | 保存先・表示・実行・実行の許可・AI・バージョンと更新（<kbd>Ctrl</kbd>+<kbd>,</kbd>） |

## フローを開いたとき

### フローの見出しの行

左から順に、次のものが並びます。

- **フロー名**：押すと、上に固定したフローと最近開いたフローが出て、ほかのフローへ切り替えられます。
- **確定の状態**：「未確定」「確定版 3」のように、スケジュールや Runner で動く版を表します。
- **検証の結果**：「エラー 2 件」「未設定 1 件」「要対応 1 件」。直すところがあるときだけ出ます。押すと下のパネルに一覧が出ます。
- **シート／フロー図**：同じフローの 2 つの読み方を切り替えます。
- **そのほか**（「…」）：元に戻す・やり直す、変数、実行結果、ステップ実行、変更履歴、フローのフォルダーのファイル、フォルダーをエクスプローラーで開く、渡す（[フローを人に渡す](../share/)）。
- **実行**：フローを実行します（<kbd>F5</kbd>）。

### シート

フローは 1 枚の紙に書かれています。上から、名前と説明、フローが使うもの（入力・テンプレート・設定・出力・自動実行・シークレット・失敗時）、その下に手順が文で順に並びます。前回の実行で操作した画面が、手順の横に付きます。長い値（HTML の全文など）は最初の数語と文字数だけが出て、押すと設定で全文を確認できます。

- 文の中の枠で囲まれた値（アドレス・ファイル名・選ぶ項目など）は、押してその場で書き換えられます。
- 手順の名前を押すと、その下に設定が開きます。繰り返しや条件は、その名前を押します。もう一度押すと閉じます。
- 開いた設定の下に「下に手順を追加」「上へ」「下へ」「この手順を止める」「削除」があります。止めた手順は取り消し線で残り、「動かす」で戻せます。
- 手順を右クリックすると、「（AI の名前）に直してもらう」「ここまで実行」・コピー・複製などのメニューが出ます。大きな変更は AI に頼みます。
- AI などが変えた手順は、紙の余白に「誰がいつ・なぜ・変更前の値」が出ます。そこで「確認済み」にするか「取り消す」かを選びます。
- 実行中は、今の手順にマーカーが付き、終わった手順にチェックが付きます。失敗した手順には、その下に理由が出ます。
- 見出しの右の「書き出す」で、シートを画像入りの HTML ファイル 1 つに保存できます（[フローを実行する](../run/#シートを書き出す)）。

### フロー図

同じフローを図で読みます。列は使うアプリ（触れた順）、時間は上から下へ進みます。繰り返しは帯、条件は破線の帯、失敗したときに行うことは右端の列に出ます。各行の番号はシートの手順の番号と同じです。行を押すと、右の欄にその手順の設定が出ます。

### フローのファイル

「そのほか」→「フローのフォルダーのファイル」で、左にフォルダーの中身が出ます。ファイルをここへドラッグすると、名前から「入力」「設定」「テンプレート」に振り分けます。

### 下のパネル

| タブ | 内容 |
|---|---|
| 実行ログ | 実行で通ったノードと、書かれたログ。「すべて」「フローのログ」「エラーと警告」で絞り込めます |
| 検証結果 | 設定の不足や誤り。押すとそのノードへ移ります |
| テスト | テストケースの一覧と結果（[テストケース](../tests/)） |

## よく使うキー

| キー | 操作 |
|---|---|
| <kbd>F5</kbd> | 実行（一時停止中は続行） |
| <kbd>F10</kbd> | ステップ実行（1 ノードずつ） |
| <kbd>F9</kbd> | 選んだノードにブレークポイントを置く・外す |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | 選んだ手順の下に手順を追加 |
| <kbd>Ctrl</kbd>+<kbd>J</kbd> | AI チャットを開く・閉じる |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | 上の帯の入力欄（AI に頼む・探す） |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | フローの中を検索 |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> ／ <kbd>Ctrl</kbd>+<kbd>Y</kbd> | 元に戻す ／ やり直す |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> ／ <kbd>Ctrl</kbd>+<kbd>V</kbd> ／ <kbd>Ctrl</kbd>+<kbd>D</kbd> | ノードのコピー ／ 貼り付け ／ 複製 |
| <kbd>Delete</kbd> | 選んだノードを削除 |

## 表示テーマと言語

「設定」→「表示」で、ライト・ダーク・PC の設定に合わせる、と、日本語・英語を切り替えられます。
