Writer は、フローを作る・直す・試す・確定するための画面です。フローを 1 つ開いたときの画面は次のようになっています。

<Screen src={writer} dark={writerDark} alt="フローを開いた Writer。上に帯、左にサイドバーとプロジェクト、真ん中にフロー図" caption="フロー「受注一覧から取引先ごとの請求書を作る」を開いたところ" />

## 上の帯

| 場所 | 内容 |
|---|---|
| 左の「SpellSheet Writer」 | メニュー（新しいフロー、設定、表示テーマなど） |
| 真ん中の「AI に頼む・フローや操作を探す」 | AI に頼みたいことを書いて送るか、フロー・ページ・操作の名前で探して開きます（<kbd>Ctrl</kbd>+<kbd>P</kbd>） |
| 「AI チャット」 | 右に AI と話す欄を開きます（<kbd>Ctrl</kbd>+<kbd>J</kbd>） |

## サイドバー

左の列です。<kbd>Ctrl</kbd>+<kbd>B</kbd> でたたむと、アイコンだけになります。

| 項目 | 内容 |
|---|---|
| フロー | このワークスペースのフローの一覧。新しいフローを作る、ファイルから読み込むのもここです |
| 確認待ち | AI が変えたフローの一覧。読んで「変更を承諾」するまで、ここに残ります（[AI の変更を確認する](../review/)） |
| 自動実行 | この PC のスケジュールと、自動実行（Worker）が動いているか（[確定とスケジュール実行](../publish-and-schedule/)） |
| シークレット | ログインの ID・パスワードや Web API のキー（[ログイン情報と個人情報](../secrets/)） |
| 最近のフロー | 最近開いたフロー。よく使うものは「上に固定」できます |
| Runner | 確定したフローを実行するだけの画面を、別のウィンドウで開きます |
| 設定 | 保存先・表示・実行・実行の許可・AI・バージョンと更新（<kbd>Ctrl</kbd>+<kbd>,</kbd>） |

## フローを開いたとき

### フローの見出しの行

フロー名の右に、次のボタンと表示が並びます。

- **フォルダーのアイコン**：フローのフォルダーをエクスプローラーで開きます。
- **紙飛行機のアイコン**（渡す…）：フローを 1 つのファイルにして人に渡します（[フローを人に渡す](../share/)）。
- **変更履歴**：誰が・いつ・何を変えたかと、名前を付けて残した「版」。版から確定することもできます。
- **確定の状態**：「未確定」「確定版 3」のように、スケジュールや Runner で動く版を表します。
- **検証の結果**：「問題なし」「エラー 2 件」「未設定 1 件」「要対応 1 件」。押すと下のパネルに一覧が出ます。

右側には表示の切り替え（**フロー図**・**手順書**・**変数**）、**ステップ実行**、**実行**が並びます。

### プロジェクト

左のパネルは、フローのフォルダーの中身です。ファイルをここへドラッグすると、名前から「入力」「設定」「テンプレート」に振り分けます。各ファイルにはどのノードが使っているかが出ます。中身の意味は[フォルダー構成](../folders/)を見てください。

### フロー図

真ん中の図がフローそのものです。上の「開始」から下の「終了」へ、ノードが上から順に実行されます。繰り返しや条件分岐は枠で囲まれ、枠の見出しに種類が出ます。

- ノードをクリックすると右の欄にそのノードの設定が出ます。ダブルクリックで画面いっぱいに開きます。
- 下の「＋ ノード追加」（<kbd>Ctrl</kbd>+<kbd>K</kbd>）でノードを足します。線の上の「＋」でも、その位置に足せます。
- 「記録」で、ブラウザやデスクトップアプリで行った操作を記録してノードにできます。
- ノードを右クリックすると、コピー・削除・「ここまで実行」・「（AI の名前）に直してもらう」などのメニューが出ます。
- 「目次」（<kbd>O</kbd>）でノードの一覧を開き、<kbd>↑</kbd> <kbd>↓</kbd> で前後のノードへ移れます。虫めがねでフローの中を検索します（<kbd>Ctrl</kbd>+<kbd>F</kbd>）。

### 右の欄

選んだノードの設定、何も選んでいなければフローの設定（名前・説明・既定の待ち時間など）が出ます。ノードの設定は、必要な項目と値を入れた項目だけが並び、ほかは「＋ 設定を追加」から足します。

### 下のパネル

| タブ | 内容 |
|---|---|
| 実行ログ | 実行で通ったノードと、書かれたログ。「すべて」「フローのログ」「エラーと警告」で絞り込めます |
| 検証結果 | 設定の不足や誤り。押すとそのノードへ移ります |
| テスト | テストケースの一覧と結果（[テストケース](../tests/)） |

## よく使うキー

| キー | 操作 |
|---|---|
| <kbd>F5</kbd> | 実行（一時停止中は続行） |
| <kbd>F10</kbd> | ステップ実行（1 ノードずつ） |
| <kbd>F9</kbd> | 選んだノードにブレークポイントを置く・外す |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | ノード追加 |
| <kbd>Ctrl</kbd>+<kbd>J</kbd> | AI チャットを開く・閉じる |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | 上の帯の入力欄（AI に頼む・探す） |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | フローの中を検索 |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> ／ <kbd>Ctrl</kbd>+<kbd>Y</kbd> | 元に戻す ／ やり直す |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> ／ <kbd>Ctrl</kbd>+<kbd>V</kbd> ／ <kbd>Ctrl</kbd>+<kbd>D</kbd> | ノードのコピー ／ 貼り付け ／ 複製 |
| <kbd>Delete</kbd> | 選んだノードを削除 |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | サイドバーをたたむ・広げる |

## 表示テーマと言語

「設定」→「表示」で、ライト・ダーク・PC の設定に合わせる、と、日本語・英語を切り替えられます。
