title: 困ったとき
description: よくあるエラーと直し方、記録の場所、問い合わせの前に確かめること。
---

フローがエラーで止まると、Writer と Runner には「何が起きたか」と「どうすればよいか」が出ます。まずはそこを読んでください。Writer で実行していれば、エラーのところで一時停止しているので、直してから続きを実行できます（[実行と直し方](../run/#エラーで一時停止したとき)）。

## よくあるエラー

### 画面の操作

| 表示 | 主な原因と直し方 |
|---|---|
| 対象の部品が見つかりません（`ELEMENT_NOT_FOUND`） | 画面が切り替わる前に操作した、表示の文言が変わった。前に待機のノードを入れるか、「画面から選ぶ」で選び直します |
| ウィンドウ〇〇が開いていません（`WINDOW_NOT_FOUND`） | アプリが起動していない、タイトルが変わった。ノードの「ウィンドウ」の探し方を見直します |
| 画面がロックされているか、サインイン画面のため、マウスとキーボードを使えませんでした（`DESKTOP_UNAVAILABLE`） | スケジュールの時刻に画面がロックされていた。[画面ロック](../publish-and-schedule/#画面を操作するフローと画面ロック)を見てください |
| 〇〇秒以内に完了しませんでした（`STEP_TIMEOUT`） | 相手の画面や処理が遅い。そのノードの待ち時間を延ばします |
| ブラウザを起動できませんでした（`BROWSER_LAUNCH_FAILED`） | Microsoft Edge か Google Chrome が入っているか確かめます |
| 人の操作が時間内に完了しませんでした（`HUMAN_TIMEOUT`） | サインインなどを待っている間に時間が過ぎた。再実行して、時間内に操作します |

### ファイル

| 表示 | 主な原因と直し方 |
|---|---|
| ファイル〇〇がありません（`FILE_NOT_FOUND`） | ファイルの場所と名前を確かめます。`input/` に置き忘れていないか見ます |
| 〇〇がほかのアプリで開かれています（`FILE_IN_USE`） | Excel などで開いているファイルを閉じてから、再実行します |
| 〇〇はすでに存在します（`FILE_EXISTS`） | 上書きしてよいなら、ノードの「上書きする」をオンにします |
| 〇〇を読み書きする権限がありません（`FILE_ACCESS_DENIED`） | フォルダーの権限と、読み取り専用になっていないかを確かめます |

### ログイン情報

| 表示 | 主な原因と直し方 |
|---|---|
| シークレット「〇〇」が登録されていないため、実行できませんでした | 出てくる「登録する」で登録します |
| シークレット「〇〇」はこのページに入力できないため、実行できませんでした | 止まったページが「入力してよいサイト」にない。正しいサイトなら追加します。知らないサイトなら追加しないでください |
| シークレットは別の PC または別のユーザーで登録されたため、この環境では読み取れません（`SECRET_KEY_MISSING`） | ワークスペースを別の PC やユーザーからコピーした。「リセットして登録し直す」で登録し直します |

### 確定・許可

| 表示 | 主な原因と直し方 |
|---|---|
| このフローには確定版がありません（`NOT_PUBLISHED`） | スケジュールや Runner は確定版を動かします。「確認待ち」か「変更履歴」→「版」で確定します |
| 〇〇はアクセスを許可したサイトに含まれていません（`SITE_NOT_ALLOWED`） | 正しいサイトなら、「設定」→「実行の許可」でサイトを追加します |
| このフローは無人実行が許可されていません（`UNATTENDED_NOT_ALLOWED`） | 「設定」→「実行の許可」の「このフロー」を確かめます |
| `POLICY_INVALID` | `policy.json` を手で書き換えて誤りがある。間違いの場所を直します。壊れたままでは「全部許可」にせず、実行を止めます |

## よくある質問

**スケジュールの時刻なのに動きませんでした。**
「自動実行」が「稼働中」か、スケジュールが「有効」か、フローが確定しているかを確かめます。PC の電源が切れていた・サインインしていなかった間の時刻は、取り戻さずに飛ばします。

**Writer では動くのに、Runner やスケジュールでは前の動きのままです。**
Writer の「実行」は作業中の内容、Runner とスケジュールは確定版を動かします。直したあとに確定し直してください。

**AI がパスワードを聞いてきました。**
SpellSheet の AI はパスワードをチャットで聞きません。Writer の上部の「ログイン情報が必要です」から登録してください。チャットにはパスワードを書かないでください。

**更新したあと、AI ツールから SpellSheet が見えなくなりました。**
AI ツールを一度起動し直してください。登録をやり直す必要はありません。

**フローを間違えて削除しました。**
削除したフローはワークスペースの `trash\` にフォルダーごと残っています。

## 記録の場所

| 知りたいこと | 場所 |
|---|---|
| フローの実行で何が起きたか | Writer の下のパネルの「実行ログ」、フローのフォルダーの `logs\` |
| 失敗したときの画面 | フローのフォルダーの `logs\`（`…_failed.png`） |
| Writer 自体が落ちたとき | `%LOCALAPPDATA%\SpellSheet\logs\` |

## 問い合わせの前に

不具合や要望は、[GitHub の Issues](https://github.com/spellsheet/spellsheet/issues) で受け付けています。送るときは、次を書いてください。

- SpellSheet のバージョン（「設定」→「バージョンと更新」）と、Windows のバージョン
- 何をしたら、何が起きたか。エラーのコード（`ELEMENT_NOT_FOUND` など）
- 実行ログ（「ログをコピー」で貼り付けられます）

:::caution
実行ログや画面の写真に、業務のデータや個人情報が写っていないか確かめてから送ってください。パスワードは自動で伏せられていますが、画面に出ていた内容はそのままです。
:::
