---

業務サイトや業務アプリのログインに使う ID・パスワード、Web API のキーは、**シークレット**として名前を付けて登録します。

考え方は 3 つです。

1. **値は人が登録する。** Writer の「シークレット」で登録します。
2. **フローと AI には名前だけ。** フローには「受注システム」のように名前だけが書かれます。値はフローのファイル・ログ・画面の写真・AI のどこにも出ません。
3. **登録したサイトにしか入力しない。** シークレットには「入力してよいサイト」を登録します。それ以外のページには入力しません。そっくりな偽サイトや、ページに仕込まれた指示に誘導されても、パスワードは渡りません。

## 登録する

サイドバーの「シークレット」→「シークレットを追加」を押します。

| 項目 | 内容 |
|---|---|
| 名前 | フローと AI がこの名前で呼びます（例：受注システム）。登録後は変えられません |
| 種類 | **ログイン**（ユーザー名とパスワード）、**API キー**（Web API に送るキー）、**OAuth アプリ**（OAuth の提供元に登録したアプリ） |
| ユーザー名・パスワード | ログインに使う値。編集のとき、パスワードを空のままにすると前の値を残します |
| 入力してよいサイト・アプリ | 1 行に 1 つ。例：`https://orders.example.co.jp`。デスクトップアプリは `app:billing.exe` |
| MFA の設定キー | 任意。認証アプリ用の QR コードの横に出るキー。ワンタイムコードを自動で入力します |
| 保存先 | **SpellSheet**（暗号化してワークスペースに保存、既定）か **Windows の資格情報マネージャー** |
| メモ | 任意。何のアカウントかを書いておくと、ほかの人にも分かります |

一覧には、そのシークレットを使っているフローも出ます。

### Windows の資格情報マネージャーを使う

会社の決まりでパスワードを資格情報マネージャーに置いている、パスワードの変更をそちらだけで済ませたい、というときは、保存先を「Windows の資格情報マネージャー」にして、「資格情報のアドレス」を選びます。使えるのは「汎用資格情報」だけです。汎用資格情報は、コントロール パネルの「資格情報マネージャー」→「Windows 資格情報」→「汎用資格情報の追加」で追加できます。

### AI から頼まれたとき

AI はパスワードをチャットで聞きません。ログインが必要になると、Writer の上部に「ログイン情報が必要です」と出ます。「登録する」を押すと、名前と入力してよいサイトが入った登録フォームが開くので、ユーザー名とパスワードだけを入れて「登録」を押します。

## フローで使う

ノードの設定でユーザー名やパスワードを入れる欄は、「文字」と「シークレット」を切り替えられます。「シークレット」にして、名前と項目（ユーザー名・パスワード・ワンタイムコード）を選びます。

### 同じサイトに複数のアカウントがあるとき

アカウントごとに別の名前で登録します（例：「受注システム（経理）」「受注システム（申請）」）。実行のたびに選びたいときは、ノードの設定に出る「同じサイトのシークレットがほかに N 件あります。実行のたびに選ぶ」を押します。アカウントを選ぶ入力ができ、実行のときに一覧から選べるようになります。

### ログイン状態を保つ

「ページ表示」ノードの「ログイン状態の名前」にシークレットの名前を入れると、前回のログイン状態（Cookie など）で開き、終わるときに保存し直します。2 回目からはログイン画面を飛ばせます。保存した状態もシークレットと同じ鍵で暗号化します。

### MFA（多要素認証）

- **認証アプリのワンタイムコード**：MFA の設定キーを登録しておけば、項目「ワンタイムコード」で毎回いまのコードを入力できます。
- **スマホでの承認・SMS など**：「手動操作の待機」ノードを置きます。実行が止まって「操作を待っています」と出て、ブラウザが前面に来ます。Writer が後ろにあるときは、Windows の通知でも知らせます。

## 伏せ字と画面の塗りつぶし

- 実行ログ・エラー・実行の記録では、パスワードとワンタイムコードが `***` に置き換わります（ユーザー名は画面にも出るので伏せません）。
- 画面の写真では、パスワード欄とシークレットを入力した欄が黒く塗られます。

## 個人情報

氏名・住所・メールアドレス・顧客の行など、個人情報を入れる変数には「個人情報」のチェックを付けます。

- その値は、実行ログ・フローの `logs/`・エラー・実行の記録・通知・AI が読む結果で `***` に置き換わります。
- 書き出したファイルや「AI に渡す用にコピー」には、初期値が入りません。
- テストケースとして保存するときも外します。

:::caution[伏せられないもの]
画面の写真には、画面に出ている個人情報がそのまま写ります（パスワード欄は塗られます）。画面に個人情報が出る業務では、手順書の「隠す」で塗るか、失敗したときの画面の保存を止めてください（ワークスペースの `policy.json` の `records.failureScreenshots` を `false`）。
:::

## 別の PC にコピーしたとき

シークレットの値の鍵は、登録した Windows ユーザーの資格情報マネージャーに 1 件だけ置かれます。そのため、ワークスペースのフォルダーを別の PC や別のユーザーにコピーすると、値は読めません。そのときは「シークレット」に出る「リセットして登録し直す」で消してから、登録し直してください。
