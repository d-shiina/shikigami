## 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10・11（64 ビット） |
| 権限 | 管理者権限は要りません。使う人のユーザーごとにインストールします |
| ディスク | インストーラーは約 210 MB です（ブラウザ操作や OCR の部品を含みます） |
| ブラウザ | Web の操作には Windows に入っている Microsoft Edge をそのまま使います（Google Chrome も選べます） |
| AI | フローを作るときだけ、Claude Code・OpenAI Codex・Gemini CLI・GitHub Copilot・Cursor のどれかが使える契約が要ります。動かすだけなら要りません |

## インストールする

1. 製品サイトの[ダウンロードのページ](../../download.html)で「ダウンロード」を押します。`SpellSheet.Writer_<版>_x64-setup.exe` が保存されます。
2. ダウンロードしたファイルを開きます。Windows の確認画面が出たときは、下の「初めて開くときの確認画面」のとおりに進めます。
3. インストーラーの案内に沿って「次へ」「インストール」と進め、「完了」を押します。
4. スタートメニューに「SpellSheet Writer」と「SpellSheet Runner」が並びます。

### 初めて開くときの確認画面

インストーラーにまだコード署名がないため（署名は準備中です）、Windows が確認の画面を出すことがあります。製品サイトか GitHub のリリースからダウンロードしたファイルであれば、次の手順で進めて問題ありません。

- **Edge が「一般的にダウンロードされていません」と止めたとき**：ダウンロードの一覧でファイルの「…」から「保存」を選び、次の画面で「詳細表示」→「保持する」を選びます。
- **青い「Windows によって PC が保護されました」の画面が出たとき**：左下の「詳細情報」を押すと「実行」ボタンが出るので、それを押します。アプリ名が `SpellSheet.Writer_…_x64-setup.exe` であることを確かめてから進めてください。

:::caution[会社の PC で「実行」が出ないとき]
社内の設定でブロックされています。情報システム部門に相談してください。
:::

ダウンロードしたファイルが公開しているものと同じかは、PowerShell で確かめられます。表示された値が、ダウンロードのページの「SHA-256」と同じなら同じファイルです。

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\SpellSheet.Writer_…_x64-setup.exe"
```

## 最初に起動したとき

スタートメニューから「SpellSheet Writer」を開くと、「何を自動化しますか？」の画面が出ます。

- **AI に依頼**：やりたいことを書いて送ると、AI がフローを組み始めます。初めてのときは、使う AI を選んで導入とサインインをします（[AI と MCP の登録](../ai-and-mcp/)）。
- **空のフローを作る**：自分でノードを並べて作ります。

## 更新

新しい版が出ると、Writer が起動したときに見つけて、裏でダウンロードします。準備ができると左下の「設定」に印が付きます。

- 「設定」→「バージョンと更新」で「再起動して更新」を押すと、すぐに入れ替わります。
- 押さなくても、Writer を閉じたときに入れ替わります。

手で入れ直す必要はありません。フロー・ログイン情報・スケジュール・設定はそのまま引き継がれます。

## アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」で「SpellSheet Writer」を選び、「アンインストール」を押します。

作ったフローや実行の記録は、アンインストールしても保存先のフォルダーに残ります。消したいときは、[フォルダー構成](../folders/)を見て保存先のフォルダーを削除してください。
