---
title: 用語集
description: SpellSheet の画面とこのマニュアルで使う言葉。
---

| 言葉 | 意味 |
|---|---|
| フロー | 1 つの業務を自動で行うための手順。ノードを上から順に並べたもの |
| ノード | フローの中の 1 つの操作（「クリック」「行の読み取り」「ファイル保存」など） |
| サブフロー | ほかのフローから呼び出して使うフロー。「サブフロー呼び出し」ノードで呼びます |
| フロー図 | フローを上から下への図で表した画面 |
| 手順書 | フローを A4 の業務手順書の形で読む画面。画面の写真付き |
| 変数 | フローの中で値を入れておく名前。「受け取る」変数は実行のときに聞かれる入力になります |
| 部品 | 画面のボタンや入力欄に名前を付けたもの。いくつものノードで使えます |
| 作業中の内容 | いま編集しているフローの内容。Writer の「実行」と AI の試し実行で動きます |
| 版 | フローの内容に名前を付けて残したもの。あとから比べたり戻したりできます |
| 確定・確定版 | 人が確かめて「この版を動かす」と決めること、その版。Runner とスケジュールは確定版だけを動かします |
| 確認待ち | AI が変えて、まだ人が確かめていないフロー |
| 期待する結果 | AI が変更のときに書く「この入力なら、この結果になる」。テストケースとして保存されます |
| テストケース | 「この入力で実行すると、こう終わって、出力はこうなる」を書いたファイル。フローのフォルダーの `tests/` |
| 一時停止 | 実行を止めたまま、続けられる状態。エラーのとき、ブレークポイント、ステップ実行で止まります |
| ブレークポイント | Writer で実行したとき、そのノードの前で一時停止させる印（<kbd>F9</kbd>） |
| ワークスペース | フローを保存するフォルダー。共有フォルダーにすると何人かで使えます |
| フローのフォルダー | フロー 1 本ごとのフォルダー。`input/`・`output/` などを持ちます |
| シークレット | ログインの ID・パスワード、Web API のキー。名前を付けて登録し、値は暗号化して保存します |
| 個人情報（変数） | ログや記録で `***` に置き換える値の印 |
| 実行の許可 | フローが開いてよいサイト・起動してよいアプリと、AI の操作に承認が要るかの設定（`policy.json`） |
| 無人実行 | 人が画面の前にいない実行。スケジュールによる実行やコマンドでの実行 |
| 自動実行・Worker | スケジュールどおりにフローを実行する、画面の裏で動く仕組み |
| スケジュール | いつフローを動かすかの決まり（毎日・毎月・一定の間隔・ファイルやメールが届いたら） |
| Writer | フローを作る・直す・試す・確定する画面 |
| Runner | 確定したフローを選んで実行するだけの画面 |
| 配布フォルダー | 確定版の `.spx` を置き合う共有フォルダー。新しい版が置かれると知らせます |
| `.spx` | フローを人に渡すための 1 つのファイル |
| カスタム ノード | 後から追加するノード（AI-OCR・社内システム・SaaS など） |
| MCP | AI ツールが SpellSheet を操作するための、つなぎ方の決まり（Model Context Protocol） |
| AI チャット | Writer の右に開く、AI と話す欄（<kbd>Ctrl</kbd>+<kbd>J</kbd>） |
| 要対応 | AI には見えないため、人が Writer ですること（画面から選ぶ、ログイン情報の登録など） |
