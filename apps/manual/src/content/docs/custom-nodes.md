title: プラグイン
description: クラウド型 AI-OCR・社内システム・SaaS などのノードを後から追加する、更新する、外す。
---

SpellSheet に最初から入っているノード（ブラウザ・デスクトップアプリ・Excel・Word・メール・ファイル・PDF・データベース・Web API など）のほかに、**プラグイン**を後から追加できます。クラウド型の AI-OCR、社内システム、SaaS の API などを、ノードとして使えるようにするものです。

追加したノードは「＋ ノード追加」の一覧に並び、AI にも伝わります。

## 開く

左上の「SpellSheet Writer」→「プラグイン」を押すと、プラグインのページが開きます。

| タブ | 内容 |
|---|---|
| インストール済み | この PC に入っているプラグイン。状態・発行元・ノードの数・バージョン・外部への送信が並びます |
| 一覧 | SpellSheet 公式の一覧など、インストールできるプラグイン |

## インストールする

### 一覧から

1. 「一覧」タブで、使いたいプラグインを選びます。
2. 内容の確認の画面で、追加されるノード、**外部へ送信するデータ**、必要なシークレット、起動するプログラムを確かめます。
3. 「インストール」を押します。

一覧からは、一覧に載せたときと同じ中身（版と SHA-256）であることを確かめたものだけをインストールします。「公式」の印は、SpellSheet 公式の一覧に載っていて、載せる前に自動の検査と人の確認を通っているものです。

### ファイル・URL・GitHub から

「インストール」を押し、「入手先」に zip ファイル・https の URL・GitHub のリポジトリ（`https://github.com/…`）を入れて「内容を確認」を押します。GitHub のリポジトリの場合は、最新のリリースに付いている zip を使います。

:::caution[発行元を信頼できるときだけ]
プラグインはこの PC でプログラムとして動き、ファイルの読み書きや通信ができます。発行元を信頼できる場合だけインストールしてください。会社で使うときは、情報システム部門の決まりに従ってください。
:::

インストールや更新のあとは、Writer の再起動で反映されます。AI ツールにも再起動のあとに伝わります。

## 更新・無効化・アンインストール

「インストール済み」で選んで、次の操作ができます。

| 操作 | 内容 |
|---|---|
| 更新の確認 | 新しい版があれば「更新あり」と出ます。「更新」で入れ替えます |
| 無効にする | 一時的に使わないようにします。「有効にする」で戻せます |
| アンインストール | この PC から外します。このプラグインを使うフローは、もう一度インストールするまで検証エラーになります |

一覧から取り下げられたプラグインを使っているときは、理由とともに知らせが出ます。無効にするかアンインストールしてください。

## ほかの一覧を足す

組織やコミュニティが自分の一覧を公開しているときは、「一覧」タブの下で一覧の URL（`https://…/index.json`）を足せます。同じ名前のプラグインが複数の一覧にあるときは、上にある一覧のものを使います。

## フローを渡すとき

プラグインを使うフローを人に渡すと、受け取る人の画面に「プラグイン『〇〇』」が必要なものとして出て、その場で「入れる」ことができます（[フローを人に渡す](../share/#受け取る)）。

プラグインを自分で作る方法は、開発者向けの[プラグインの説明](https://github.com/spellsheet/spellsheet/blob/main/docs/ja/extensions.md)にあります。
