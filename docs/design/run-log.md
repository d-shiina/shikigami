# 実行ログ

Studio の下のパネルの「実行ログ」は、実行が通ったノードを上から順に並べたツリーにする。一行ずつの文字の流れ（以前の形）では、どのノードに何秒かかったか、繰り返しの何件目で止まったか、どこまで進んだかが読めなかった。

## 手本にしたもの

| 製品 | 取り入れたこと | 取り入れなかったこと |
| --- | --- | --- |
| GitHub Actions のログ | ステップごとに 1 行、✓／× と時間。終わったところは畳み、失敗したところは開く | 生のコンソール出力の等幅表示（業務の人が読む文ではない） |
| Vercel・Chrome の Performance | 実行全体を共通の時間軸にした帯で、どこに時間を使ったか一目で分かる | 細かい目盛り・ズーム |
| UiPath の出力パネル | 種類での絞り込み（エラーと警告だけ）、ログのコピー | 情報・警告・エラーの数のボタン 3 つ（1 つの切り替えで足りる） |
| Power Automate for desktop | ― | 行番号でノードを示すこと（debug-runs.md「ログからノードへ」） |

## 静かに保つ

業務の人が読むので、1 行は「終わり方の印・名前・かかった時間」だけにする（Daiki「今の人はこれが読みやすいのか？」を受けて引き算した）。

- 名前は人が付けた表示名。種類の名前（「繰り返し（リスト）」など）とアイコンは、表示名がないときの代わりにだけ使う
- 開始からの時間と時間軸の帯は、行を指したときだけ出す
- 実行全体の 2 割以上（かつ 1 秒以上）かかった普通のノードだけ、時間を太字にする。どこで時間を使ったかを、帯なしでも拾える

## 行の種類

- **ノードの行**：終わり方の印・名前・かかった時間（指すと開始からの時間と帯）。押すとフロー図のそのノードへ移る（サブフローの中なら入って見せる）。再試行して通ったときは「2 回目で成功」。
- **枠の行**：繰り返し・分岐・グループ・try・並列・待機・サブフロー呼び出しは、中で動いたノードを下に字下げして持つ。サブフロー呼び出しは「→ 呼んだフロー名」を添える。
- **回の行**：繰り返しの中は「1 件目」（リストの繰り返し）、「1 回目」（それ以外）に分ける。本体の最初のノードがもう一度始まったところで次の回とする。
- **エラーの行**：失敗のいちばん内側のノードの下にだけ、エラーの文を朱で出す。外側の枠（繰り返し・呼び出し）は × の印だけで、同じ文を繰り返さない。
- **フローのログ**：「ログ出力」ノードはそのノードの行が書いた文そのものになる（吹き出しの印、本文の濃さ）。
- **SpellSheet のログ**：ノードが自分で書いた行（「3 行を読み込みました」など）は、そのノードの下に小さく灰色で出す。警告は琥珀、エラーは朱の印。
- **始まりと終わり**：始まりの行に開始時刻、終わりの行に「完了しました／エラーで中断しました／中止しました」と全体の時間。

## 開く・畳む

勝手に開いているのは、実行中・失敗・警告を含むところと、繰り返しの最後の回。それ以外は畳む。人が開け閉めしたものはその実行のあいだ覚えておく。普通のノードの下のログ行は畳まない（そのノードの行の続き）。

## 色

ui-principles.md のとおり、色は状態と選択だけ。印は緑（完了）・朱（失敗）・橙（実行中）・水色（一時停止）。帯は、普通のノードは灰色、実行中は橙、失敗は朱。中にノードを持つ枠と回の帯は薄い灰色にする（色を付けると、中のノードの色を何度も繰り返して画面が赤や橙だらけになる）。フロー図で選んだノードの行は選択の青。

## 絞り込みとコピー

- 「すべて」「フローのログ」（「ログ出力」ノードの行だけ）「エラーと警告」。絞ったときも、その行に至る枠の行は残す。
- コピーは全部を開いた形の文字にする（時間・字下げ・✓／×・名前・時間）。AI やサポートに貼る用。

## 実装

- `lib/runTrace.ts`：`stepStarted` / `stepFinished` からノードの実行の木（`RunTrace`）を作る。親は「今動いていて、中にノードを持つ種類」のうち最も新しいもの。並列の枝が交互に進んでも、普通のノードが親になることはない。再試行は同じ行のまま回数を数える。
- 店（`store.ts`）は実行のイベントごとに木を進め、ログ行にどのノードの実行のものか（`node`）と、始まり・終わり・一時停止・再開の印（`mark`）を付ける。ノードの失敗としてのエラー行には `fromStep` を付け、木ではノードの行の下に出す。
- 画面は `components/RunLog.tsx`。ID は押したときの行き先としてだけ持ち、画面には出さない。
