# データテーブル（一覧の表）

Studio で「たくさんの同じ種類のものを見比べて、探して、まとめて扱う」一覧は、すべて同じ部品 `apps/studio/src/components/DataTable.tsx` で作る（2026-11-08、Daiki「データテーブルが適してるところは全て同じ仕組みにしよう」）。手本は Linear・Notion・shadcn/TanStack の表。

## 形

- **枠付きの表**：角丸 8px の枠、影は付けず紙の上に平らに置く。見出しは文字と下線だけ（帯にしない。ページの見出しの帯と 2 段に重ねないため、2026-11-08 Daiki）で、ページを下へ送っても上に残る。下端に件数の行（「12 件中 6 件」「3 件を選択中」、Shift・Ctrl の案内）。一覧のうち「表」は枠で囲み、手順・履歴・ログのような読み物の一覧は今までどおり箱なしにする（表は列を読み比べるもので、枠と見出しの帯が列の目安になるため）。
- **1 行 1 件**：行の高さはそろえ、セルは 1 行で切る（全文はホバーの title）。「表示」で「標準」「詰める」を選べる。
- **状態はピル**：薄い面に点と言葉（確定済み＝緑、確定後に変更＝橙、未確定＝灰）。タグは細い枠の札。
- **並べ替え**：見出しを押すと昇順、もう一度で降順。矢印は並べ替えている列だけに出し、ほかは指したときだけ。
- **列の幅**：幅の決まった列は見出しの右端をドラッグで変え、ダブルクリックで戻す。幅の決まっていない列（名前など）が残りを分ける。狭い画面では大事でない列から隠す（`hideBelow`、ページに `@container`）。幅は `<th>` に持たせる（`<col>` だと隠した列の幅が残るため）。
- **絞り込み**：上の帯に検索と、列ごとの点線のボタン（`FacetFilter`）。押すと値の一覧が出て、いくつでも選べ、それぞれに件数を出す（件数はほかの絞り込みを効かせた数）。選ぶとボタンに選んだ値が並ぶ。1 つでも効いていれば「絞り込みを外す」。
- **表示**（`ViewMenu`）：行の高さ、グループ分け（列の `group`）、出す列。選んだ見方は表ごとに `storageKey` で覚える。
- **選択**：左端のチェック。Shift で範囲、Ctrl（行のクリックでも）で 1 件ずつ、Space で今の行。選ぶと画面の下に浮かぶ帯（`SelectionBar`）に件数とまとめての操作が出る。Esc か × で外す。一括操作は画面に出ている行の選択だけを対象にする（絞り込みで隠れた行は消さない）。
- **行の操作**：行を押す・Enter で開く。右端の「…」と右クリックで同じメニュー。↑↓ で行を移る。
- 塗りボタンは画面に 1 つ（右上の追加・新規作成）。ほかの入口はその ▾ にまとめる。

## どの一覧を表にするか（2026-11-08 の棚卸し）

| 一覧 | 表にするか | 理由 |
|---|---|---|
| フロー | する | 数が増え、確定・自動実行・更新を見比べて探す |
| シークレット | する | 種類・使える先・使っているフローを見比べ、使っていないものを片付ける |
| 変数（フローの「変数」の見方） | する | 向き・型・初期値を見比べ、セルでそのまま直す |
| 自動実行のスケジュール | した | 次回・前回・状態（実行中・有効・実行されない・無効）を見比べ、まとめて有効・無効・削除。フローは名前の下、画面ロックの注意は表の上に 1 度だけ |
| プラグイン（インストール済み・一覧） | した | 発行元・ノード数・外部への送信・版・状態を見比べ、まとめて有効・無効・アンインストール。一覧（カタログ）の「インストール」ボタンは常に見える列に置く |
| 確認待ち | しない | 1 件ずつ中身（変更点）を読んで判断する |
| 実行ログ・変更履歴・版 | しない | 時間の順に読むもので、並べ替えると意味がなくなる |
| テスト・問題のパネル | しない | 右や下の狭い欄で、1 件ずつ直しに行く |
| プロジェクトのファイル | しない | フォルダーの木 |
| 見本・実行画面 | しない | 選ぶための大きな入口（実行画面は操作する人向け） |

## 行の状態と有効のスイッチ

- 行の状態は `StatusBadge`（点＋言葉の丸い札）でそろえる。色は 緑＝動く・灰＝止めた・赤＝動かない理由がある・青＝実行中や開発用・黄＝注意。絞り込みの点も `toneDot` で同じ色。
- 行ごとの「有効」は `Switch`（チェックボックスではない。行を選ぶチェックと見分けるため）。押しても行は開かない。
- 行の「…」は `RowMenuButton`。右クリックと同じメニューを出す。
