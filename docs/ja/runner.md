# 実行画面

[English](../runner.md) | 日本語

Studio はシナリオを作る人の道具です。動かすだけの人には、小さな別のウィンドウ **Shikigami 実行** があります。公開されたシナリオを選び、入力を埋めて「実行」を押し、結果を見ます。

- Studio の左のサイドバーの「実行画面」から開きます。Studio を `--runner` を付けて起動すると、この画面だけが開きます（編集しない人のショートカット向け）
- 並ぶのは公開されたシナリオだけで、動くのはいつも公開版です。公開は Studio の「確認待ち」でします（[policy.md](policy.md)）
- 人が起動して見ているので、Studio の「実行」と同じく、無人実行の決まり（`policy.json` の `unattended`）は当てはまりません。実行の記録はほかと同じに残ります（`origin.trigger` は `studio`、`requestedBy` は `runner`）
- 処理していないエラーで実行は終わります。ここでは止めて直すことはせず、何が起きてどうすればよいかを Studio と同じ言葉で出します

## 入力のフォーム

フォームはシナリオの入力変数（`direction` が `input` か `inOut`）から作るので、作る人も AI もフォームのために何も書きません。

| 変数 | 入力欄 |
|---|---|
| `description` | 項目名（1 行目）。なければ変数名 |
| `type: "string"` | 文字の欄 |
| `type: "number"` | 数の欄（`120,000` のようにカンマ付きでもよい） |
| `type: "boolean"` | チェックボックス |
| `type: "array"` | 1 行に 1 つ（JSON の配列でもよい） |
| `type: "object"` | JSON |
| `secret: true` | パスワードの欄 |
| `default` | 欄の最初の値。初期値がない欄は必ず埋めます。初期値があれば、空のままで初期値が使われます |

## 実行中と、終わったとき

実行中は、シナリオの一番上の段のノードを並べ、通ったものに印を付け、今のノードを出します。終わると、出力変数（説明を項目名に）と、その実行が `output/` に書いたファイル（「開く」と「フォルダーを開く」）を出します。失敗したときは、エラーのコードとどうすればよいかを出します。
