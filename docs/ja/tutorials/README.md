## はじめる前に

- Shikigami Studio を入れて起動する（[README](../../README.ja.md)）
- Studio の左上「Claude Code」（Ctrl+J）で AI のペインを開き、サインインを済ませる
- 見本のファイルは `examples/tutorials/` にあります。完成形のシナリオ（`*.shikigami.json`）もあり、シナリオの画面の「ファイルから読み込む」で開けます。AI を使わずに中身を見たいときはこちらを使ってください

## どのチュートリアルにも共通の流れ

1. **シナリオを作り、ファイルを置く**：シナリオの画面で「新規作成」。左のプロジェクトの棚に見本のファイルをドロップすると、名前から `input/`・`templates/` などに振り分けられます
2. **AI に頼む**：各ページの「頼む文」を AI のペインに貼ります。AI はノードを少しずつ足し、フロー図がそれを追います
3. **確かめる**：サイドバーの「確認待ち」で、変わること・外への影響・AI の試し実行の結果を読み、「確認して公開」を押します
4. **試す**：タイトルバーの「実行」（F5）。止まったときは、何が起きてどうすればよいかが日本語で出ます。「Claude Codeに直してもらう」でその場で直して続けられます
5. **毎月動かす**：公開した版は AI なしで動きます。コマンドでは `shikigami run <シナリオの ID>`。Windows のタスクスケジューラーから呼べば決まった時刻に動きます
