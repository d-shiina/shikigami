## はじめる前に

- SpellSheet Writer をインストールして起動する（[README の「使い始める」](../../README.ja.md#使い始める)）
- Writer の左上「Claude Code」（Ctrl+J）で AI のペインを開き、サインインを済ませる
- 見本のファイルは `examples/tutorials/` にあります。完成形のフロー（`*.spellsheet.json`）もあります。AI を使わずに中身を見る場合は、Writer のフローの画面の下の「見本」で「完成形を開く」を押してください（見本のファイルも一緒に入ります）。バンドルを「ファイルから読み込む」で開いても同じです

## どのチュートリアルにも共通の流れ

1. **フローを作り、ファイルを置く**：フローの画面で「新規作成」。左のプロジェクトの棚に見本のファイルをドロップすると、名前から `input/`・`templates/` などに振り分けられます
2. **AI に依頼する**：各ページの「AI に依頼する」にある文を AI のペインに貼り付けます。AI はノードを少しずつ追加し、フロー図がそれに合わせて表示されます
3. **確認する**：サイドバーの「確認待ち」で、変更内容・外への影響・試し実行の結果を確認し、「確認して公開」を押します
4. **試し実行する**：タイトルバーの「実行」（F5）。エラーで一時停止した場合は、何が起きたか、どうすればよいかが表示されます。「Claude Code に修正を依頼」でその場で修正して続行できます
5. **毎月実行する**：公開版は AI なしで実行できます。サイドバーの「自動実行」でスケジュールを追加すると、決まった日時に自動で実行されます。現場の人は実行画面「SpellSheet Runner」から実行できます
